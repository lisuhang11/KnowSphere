# PPT 结构

把一次演示收成「封面 → 议程 → 主体 → 收束」，再交给 `generate_pptx`。

## 何时使用

- 用户要做演示文稿、汇报、路演、答辩、培训课件
- 用户只给了主题，还没说页数、受众或每页写什么
- 用户嫌现有稿太散、太长、或每页字太多，要重排结构

不要用本技能：只抽取 PDF 文字（用 `pdf-extract`）、只检索知识库（用 `doc_retrieval`）、已经有完整大纲只差出文件（直接 `generate_pptx`）。

## 默认假设

用户没说清楚时：

- 受众：内部汇报
- 页数：6–10 页内容页（另加封面，由 `generate_pptx` 自动加）
- 时长：约 8–12 分钟口播

有明确页数/受众就按用户的来，不要擅自加长。

## 页型

按这个顺序组织，缺的类型可省略，不要颠倒：

1. **封面信息**：主题、场合、汇报人（写入 `generate_pptx` 的 `title`，不要再做一页空封面）
2. **议程 / 结论先行**（1 页）：3–5 条将要讲的模块，或先抛核心结论
3. **主体**（每页一个论点）：背景 → 现状/数据 → 方案 → 计划/风险，按用户任务取舍
4. **收束**（1 页）：结论、下一步、要拍板的事项

## 每页写法

- 页标题写成**结论**，不要写成范畴。例如「Q3 营收低于目标 12%」，不要「营收情况」
- 每页 3–5 条 bullets，每条不超过约 20 个汉字
- 一条一个事实或动作；禁止段落、禁止在 bullets 里塞子列表
- 数字带单位和比较基准（同比/环比/目标）
- 同一页不要混两件无关的事；拆页，不要堆

## 流程

1. 用一句话确认主题、受众、页数（用户已说的不要再问）。
2. 列出每页的 `title` + `bullets` 草稿；缺事实再去检索，不要编造。
3. 调用 `generate_pptx`：
   - `title`：整份文稿标题
   - `slides`：内容页列表，每项 `{ "title": "...", "bullets": ["...", "..."] }`
   - 不要一次超过 20 页
4. 工具成功返回后再告诉用户生成了什么。改某一页时基于完整大纲重新调用 `generate_pptx`。
